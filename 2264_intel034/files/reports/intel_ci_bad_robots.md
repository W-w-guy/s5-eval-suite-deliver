# 情报简报评测报告（prompt-set=ci_bad_robots）

> 样例全部虚构：域名使用 example 保留域名，企业与人物均不存在。
> 生产中 AI 输出一律进复核队列，不得直接对外发送；AI 不计算任何金额。

## 一、11 项指标与门槛

| # | 指标 | 实测 | 门槛 | 判定 |
|---|---|---|---|---|
| 1 | 正文提取平均相似度 | 1.0 | >= 0.95 | 通过 |
| 2 | 发布日期准确率 | 1.0 | >= 0.98 | 通过 |
| 3 | 转载归组 F1 | 1.0（误合并 0） | >= 0.95 且 == 0 | 通过 |
| 4 | policy_type 准确率 | 1.0 | >= 0.85 | 通过 |
| 5 | 截止日期准确率 | 1.0 | >= 0.9 | 通过 |
| 6 | 摘要关键事实覆盖率 | 1.0 | >= 0.8 | 通过 |
| 7 | 不一致数字/日期被标出比例 | 1.0 | == 1.0 | 通过 |
| 8 | 无原文链接进入核对队列数 | 0 | == 0 | 通过 |
| 9 | robots 禁止路径被抓取数 | 2 | == 0 | **未通过** |
| 10 | 摘要含 URL 数 | 0 | == 0 | 通过 |
| 11 | 送模型文本联系方式残留 | 0 | == 0 | 通过 |

## 二、样本与丢弃

| 项 | 数量 |
|---|---|
| 金标用例 | 12 |
| 成功处理条目 | 11 |
| 丢弃（含无原文链接、抓取失败） | 1 |
| 因数字/日期不一致进核对队列 | 0 |

无原文链接的条目**直接丢弃、不进核对队列**（指标第 8 项＝0）。
让它们进队列等于把无法核对的内容丢给人工。

## 三、转载归组明细

| 项 | 值 |
|---|---|
| 精确率 | 1.000000 |
| 召回率 | 1.000000 |
| F1 | 1.000000 |
| 误合并对数（应为 0） | 0 |
| 金标对数 / 预测对数 | 4 / 4 |

## 四、门槛汇总

**未达标项：robots 禁止路径被抓取数**

CI 中任一门槛不达标时本命令退出码非 0（1），可直接作为合并拦截条件。

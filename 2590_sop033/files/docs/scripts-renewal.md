# 关怀话术 · 续约预警

> 由 `tools/build_docs.py` 从模板 `scripts` 段生成。变量 `{企业名称}` `{联系人}` 在发送前由系统替换；
> 所有示例数据均为虚构，不使用任何真实个人信息或企业信息。

## step1_diagnose

```
您好{联系人}，我是{企业名称}的会员经理。会籍还有约三个月到期，想约您二十分钟聊聊这一年的使用感受，也听听下一步的规划。
```

## step2_care

```
{联系人}您好，根据上次沟通，我们为您准备了一份关怀方案：{关怀动作}，计划日期 {计划日期}。不合适的话我们再调。
```

## step4_quote

```
续约方案里涉及的金额由报价模块按价格规则表统一计算，我这边不口头报价，稍后把关联的报价单编号发给您核对。
```

## step5_confirm

```
{联系人}您好，续约相关的事项已记录完毕。最终会籍状态会由我们在 CRM 中确认后同步给您，以系统记录为准。
```

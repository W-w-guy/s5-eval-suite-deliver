# 折扣审批路由表与 12 个越权审批场景（全部虚构）

口径（均为虚构值）：

```
角色折扣上限：招商业务员 5.0% / 招商主管 10.0% / 运营总监 15.0% / 总经理 20.0%
超出 = 折扣率 − 发起人上限；等于上限（超出 = 0）不需审批
区间判定（左开右闭）：
  0 < 超出 ≤ 5 个百分点  → R01 招商主管
  5 < 超出 ≤ 10 个百分点 → R02 运营总监
  超出 > 10 个百分点     → R03 总经理
特殊条款路由：免押金 → R04 运营总监；延期付款 → R05 运营总监；免租期 > 30 天 → R06 总经理
同时命中折扣与特殊条款：取层级更高的一条，不叠加串行
审批人与发起人同角色：跳过该节点，从下一节点起
节点超时：自动上升一级；任何情况下不允许自动通过
中途修改报价：原审批作废，按新口径重新审批
```

> 百分点数值内部以「百分点 × 10」的整数参与运算（51 表示 5.1 个百分点），不使用浮点。
> 企业、产品、角色人员均为虚构，不含真实客户信息。

| --- | --- | --- | --- | --- | --- | --- |

## P01（情形：D1）

场景：招商业务员报价折扣 3.0%，未超其 5.0% 上限，无特殊条款。

**发起人与报价摘要**

| 项 | 值 |
| --- | --- |
| 发起人角色 | 招商业务员（上限 5%） |
| 产品 | B 级独立办公室 |
| 租期 | 12 个月 |
| 折扣率 | 3% |
| 特殊条款 | 无 |

**逐步判定**

1. 超出百分点 = 折扣 3 − 上限 5 = **−2** 个百分点。
2. 超出 ≤ 0 → **等于或低于上限，不需审批**。
3. 命中路由：**无**；期望审批链：**（无需审批）**。

**边界说明**：区间为左开右闭 —— 恰好等于上界（如超出恰好 5 个百分点）仍留在本档，
只有**超过**上界才升档；折扣恰好等于角色上限（超出 = 0）不需审批。

结果：路由 **无** / 审批链 **（无需审批）** / 时限 **0** 小时 / 期望结果 **直接生效**

备注：折扣 3% 未超出招商业务员上限 5%，且无特殊条款 → 不需审批，直接生效。

只有**超过**上界才升档；折扣恰好等于角色上限（超出 = 0）不需审批。

结果：路由 **R05** / 审批链 **运营总监** / 时限 **12** 小时 / 期望结果 **驳回后重提**

备注：命中 R05（含特殊条款：延期付款）；同时命中折扣路由 R01 与条款路由 R05，取层级更高的 R05，不叠加；上一轮被驳回，重提后按原路由重新审批。

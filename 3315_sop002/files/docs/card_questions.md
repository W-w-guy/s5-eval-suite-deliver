# 能力卡共建：10 个引导问题（全部虚构口径）

> 用途：把会员能力梳理成可撮合的结构化字段。按顺序提问，未答项标注「待补」。

## 开场话术

```
{联系人}您好，今天想用 10 个问题把{企业名称}的能力梳理成一张卡，方便我们后续帮您做撮合。您怎么方便怎么答，我来记录。
```

## 10 个问题

1. **主营业务**：贵司的主营业务用一句话怎么描述？
2. **产业位置**：目前在产业里处于哪个环节（上游/中游/下游/服务方）？
3. **期望对接**：最希望在这栋楼里遇到什么样的企业？（客户/供应商/合作方/同行）
4. **可提供资源**：贵司能对外提供什么资源或能力？（可作为别人的供给）
5. **近期难题**：近期最想解决的一个业务难题是什么？
6. **团队构成**：团队规模与关键岗位构成大概是什么样？
7. **既有案例**：过去一年有没有成功撮合或合作的案例可以匿名分享？
8. **活动偏好**：对会员活动有什么偏好？（行业沙龙/路演/闭门会/培训）
9. **跟进节奏**：希望我们多久跟进一次比较合适？
10. **延伸服务**：除办公空间外，还希望平台提供哪类服务？

## 落库字段映射

| 问题 | 能力卡字段 | 是否必填 |
| --- | --- | --- |
| 1 | 主营业务 | 必填 |
| 2 | 产业位置 | 必填 |
| 3 | 期望对接 | 必填 |
| 4 | 可提供资源 | 必填 |
| 5 | 近期难题 | 必填 |
| 6 | 团队构成 | 可选 |
| 7 | 既有案例 | 可选 |
| 8 | 活动偏好 | 可选 |
| 9 | 跟进节奏 | 可选 |
| 10 | 延伸服务 | 可选 |

> 前 5 问为能力卡必填字段（主营/产业位置/期望对接/可提供资源/近期难题），
> 后 5 问为可选补充。能力卡须经会员确认后才入库。

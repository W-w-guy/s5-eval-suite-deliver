# 入会引导各步骤检查项表（可勾选）

> 逐条勾选后才可流转下一步；未勾完不得进入下一步。

## S01 入会邀请与欢迎（会员成功顾问，3 条）

- [ ] 三个渠道是否都已发出
- [ ] 会员编号是否已生成并告知
- [ ] 资料清单链接是否可正常打开

## S02 必填资料收集（会员成功顾问，4 条）

- [ ] 营业执照副本是否已归档并核验主体名称
- [ ] 联系人名单是否已录入管理员账号
- [ ] 开票信息是否已交财务专员
- [ ] 门禁登记是否只采集最少必要信息（不含证件号）

## S03 可选资料说明（会员成功顾问，2 条）

- [ ] 是否说明了可选材料不影响入会
- [ ] 是否记录了会员的取舍结果

## S04 资料审核与退回补正（运营主管，3 条）

- [ ] 是否在 1 个工作日内给出审核结论
- [ ] 退回时是否一次性列全补正点（不挤牙膏）
- [ ] 补正后是否已复审

## S05 门禁与账号开通（前台，3 条）

- [ ] 门禁人数是否与联系人名单一致
- [ ] 是否只采集最少必要信息（姓名/所属企业/人数）
- [ ] 开通后是否取得会员「可用」确认

## S06 能力卡共建访谈（会员成功顾问，3 条）

- [ ] 10 个问题是否逐一提问并记录
- [ ] 未答项是否标注待补
- [ ] 能力卡是否经会员确认后才入库

## S07 首次到访引导（前台，3 条）

- [ ] 是否带会员走完主要动线
- [ ] 是否演示了访客邀请码的生成
- [ ] 会员提出的问题是否已记录并跟进

## S08 30 天回访（会员成功顾问，3 条）

- [ ] 是否在满 30 天时完成回访
- [ ] 满意度是否已记录
- [ ] 能力卡是否需要更新是否已判断

# DATA_PROVENANCE — 数据来源与可复核性

本交付包**不含任何真实个人信息或企业信息**。全部示例数据由脚本生成，可完整重放。

| 项 | 值 |
| --- | --- |
| 生成脚本 | `pkg/engine.py`（示例定义与业务规则）+ `tools/gen.py`（写出 docs/） |
| 生成脚本 sha256 | `aa2d38e68e7e0de03a0e2b47255d837d0f1b801cd6c970cdba5f4784942fc476` |
| 渲染脚本 sha256 | `ed6afb8c0641a1d660e8d2d49765dbb00bbf5795fa2be8e53b2f885ccb88dd62` |
| 随机性 | **无随机**。步骤、话术与时间为手写固定常量；截止时刻由纯 naive datetime 推算（不依赖系统 tzdata）；同一脚本在任何机器重跑产出字节级一致（已在 Windows 与 Ubuntu 两侧核对 sha256） |
| 种子 | 不适用（无随机数生成器） |
| 重跑命令 | `python tools/gen.py` |
| 产出规模 | 8 个步骤 / 8 类情形 / 话术 3 版（≤150 字）/ 资料清单 8 项（4 必填+4 可选）/ 能力卡 10 问 / CSV 8 行 12 列 |
| PII 扫描 | `python tools/pii_scan.py` → `scanned=35 hits=0`（手机号 / 邮箱 / 身份证 / 银行卡 四类正则） |

## 虚构声明

企业名称、人名、会员编号与全部条款均为虚构；话术一律使用变量占位，不含真实个人联系方式。

# 新会员入会引导 SOP：欢迎话术、资料清单与检查项

本包为「新会员入会引导 SOP」配套材料：欢迎话术 3 版（企业微信/短信/邮件，每版 ≤150 字且带变量占位）+ 入会资料清单（4 项必填含替代方案 + 4 项可选）+ 8 个步骤的检查项表（每步 2~4 条可勾选）+ 能力卡共建 10 个引导问题 + 步骤表与责任矩阵。全部内容为**虚构**。

## 一条命令复跑

```
python tools/gen.py             # 重新生成 docs/ 下全部交付物
python tools/verify.py          # 逐条断言 AC（23 条），任何一条失败即非零退出
python -m pytest tests -v       # 逐条列出用例名（两侧输出格式一致，便于对数）
python tools/mutate.py          # 变异测试：改坏引擎 7 处，每处都必须让 verify 变红
python tools/build_docs.py      # 由实跑结果重生成 README / DATA_PROVENANCE / ACCEPTANCE
python tools/make_zip.py        # 打包 + SHA256SUMS
```

## 口径说明

- 欢迎话术 3 版（企业微信/短信/邮件），每版不超过 150 字，一律使用变量占位。
- 字数两套口径同时判：变量记 0 字（乐观）与含占位符的原始长度（严格），两者都 ≤150 才算合规。
- 入会资料 4 项必填：营业执照副本、联系人名单、开票信息、门禁登记信息；每项必给「不提供时的替代方案」。
- 入会资料 4 项可选：Logo、官网/公众号链接、企业简介、特殊需求说明；不提供不影响入会。
- 门禁登记只采集姓名、所属企业、人数，证件号一律不收（最少必要信息原则）。
- 每个步骤 2~4 条可勾选检查项，未勾完不得流转下一步。
- 资料审核不合格时一次性列全补正点，不挤牙膏式退回。
- 能力卡共建使用 10 个引导问题，前 5 问为必填字段，能力卡须经会员确认后才入库。
- 时限两类口径不混用：S01~S07 用 work（工作日 9-18 内消耗），S08 的 30 天回访用 natural（自然时间）。
- 任何步骤不允许跳过：未完成检查项的步骤不得流转。

# DATA_PROVENANCE — 数据来源与可复核性

本交付包**不含任何真实个人信息或企业信息**。全部示例数据由脚本生成，可完整重放。

| 项 | 值 |
| --- | --- |
| 生成脚本 | `pkg/engine.py`（示例定义与业务规则）+ `tools/gen.py`（写出 docs/） |
| 生成脚本 sha256 | `1083c5873d23aa767d2857167fbec31a467caa40ad195f68c9941490a26838f1` |
| 渲染脚本 sha256 | `d77953e9f79f19c36caf36c8d044793cd73c4ff420562c4070cdcf1fdfa03572` |
| 随机性 | **无随机**。步骤、话术与时间为手写固定常量；截止时刻由纯 naive datetime 推算（不依赖系统 tzdata）；同一脚本在任何机器重跑产出字节级一致（已在 Windows 与 Ubuntu 两侧核对 sha256） |
| 种子 | 不适用（无随机数生成器） |
| 重跑命令 | `python tools/gen.py` |
| 产出规模 | 10 个步骤 / 8 类情形 / 6 条话术（3 类×2 版）/ 会前简报 7 字段双版本 / 引荐流程 9 节点 9 条带条件边 / CSV 10 行 12 列 |
| PII 扫描 | `python tools/pii_scan.py` → `scanned=32 hits=0`（手机号 / 邮箱 / 身份证 / 银行卡 四类正则） |

## 虚构声明

岗位、企业、姓名、时间与商务条款均为虚构；话术一律使用变量占位（如 {需求方联系人}），不含任何真实个人联系方式。

# 会前简报模板（两版，全部虚构）

> 使用说明：同一场洽谈必须**两版齐发**，且洽谈前 1 个工作日发出。
> 两版都只写对方「画像」，不写对方身份、企业全称与任何联系方式。

## 通用字段

| 字段 | 名称 | 内容要求 | 备注 |
| --- | --- | --- | --- |
| `brief_version` | 简报版本 | 需求方版 / 供给方版 | 同一洽谈必须两版齐发 |
| `demand_profile` | 需求画像 | 行业/规模区间/核心诉求/时间窗 | 仅需求方版填全；供给方版只写画像摘要 |
| `candidate_profile` | 候选方画像 | 能力标签/可交付范围/匹配理由 | 仅供给方版填全；需求方版只写画像摘要 |
| `match_reason` | 匹配理由 | 3 条以内，须可验证 | 不能写「感觉合适」 |
| `agenda` | 建议议题 | 3~5 条 | 两版各自不同 |
| `contact_policy` | 联系方式口径 | 「双方同意前不透露」 | 两版都要写明 |
| `owner` | 本次负责人 | 招商顾问姓名（虚构） | 同一洽谈唯一负责人 |

## 需求方版（发给需求方，介绍候选方）

```markdown
# 会前简报 · 需求方版
- 简报版本：需求方版
- 候选方画像：{候选方画像}（行业 / 规模区间 / 可交付能力标签）
- 匹配点：{匹配理由}（3 条以内，可验证）
- 建议议题：{建议议题}（3~5 条）
- 联系方式口径：**双方均同意前不透露**，本简报不含对方任何联系方式
- 本次负责人：{负责人}
```

## 供给方版（发给供给方，说明需求）

```markdown
# 会前简报 · 供给方版
- 简报版本：供给方版
- 需求画像：{需求画像}（行业 / 规模区间 / 核心诉求 / 时间窗）
- 匹配点：{匹配理由}（3 条以内，可验证）
- 建议议题：{建议议题}（3~5 条）
- 联系方式口径：**双方均同意前不透露**，本简报不含对方任何联系方式
- 本次负责人：{负责人}
```

## 填写检查

- [ ] 两版是否都已发出（缺一版即不合规）
- [ ] 两版是否都不含对方联系方式与企业全称
- [ ] 匹配理由是否 3 条以内且可验证（不能写「感觉合适」）
- [ ] 建议议题是否 3~5 条，且两版不同
